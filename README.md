# Bato: Perks of Being a Senator

A browser‑based action‑platformer built with **Phaser 3**, **Vite**, and **Vanilla JavaScript**.

## Features
- Perk system with cooldowns and visual overlay
- Audio manager with menu/zone tracks (CC0 license)
- Save/load using `localStorage`
- Touch controls and keyboard support
- Enemy spawner & basic enemy behaviours
- HUD showing health, prayer, heat, coins and active perks
- Ready for deployment on **Vercel** (SPA rewrite included)

## Development
```bash
npm install        # install dependencies
npm run dev        # start Vite dev server
```

## Build & Deploy
```bash
npm run build      # creates ./dist
vercel --prod      # deploy to Vercel (requires Vercel CLI login)
```
